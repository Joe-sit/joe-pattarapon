## สอง: โมเดลหลัก — สนามความสูงใบเดียว

หัวใจของทั้งอินโทรคือ **ไม่มีเลเยอร์** พื้นหลังกับตัวโลโก้เป็นค่าเดียวกัน
ต่างกันแค่ "สูงแค่ไหน" แล้วถูกแปลงเป็นอักขระด้วยบันไดเดียวกันทั้งจอ

```
_  •  =  +  <  :  ;  !  $  @  #  ▉
└── ฟ้าเข้ม ──┘└ ฟ้า ┘└ คราม ┘└ ส้ม ┘└ บล็อกทึบ
```

ค่าต่อช่องคือ `level = max(ภูมิประเทศ, โลโก้)` แล้วส่งเข้า ramp เดียว
"การแปลงร่าง" จึงเกิดเองเมื่อโลโก้ไต่ระดับขึ้นมาแซงภูมิประเทศ ไม่ต้องมีรอยต่อ

ระดับของโลโก้:

```
level = r × heat × (0.70 + 0.24·fill + 0.28·solid)
```

- `r` = ความทึบของรูป + คอนทัวร์ที่เบลอออกไป (สูงสุด 1.25)
- `heat = ink^0.35` — ไต่บันไดเร็วกว่าเชิงเส้น
- ค่าฐาน `0.70` ทำให้ส่วนที่มีรูปแล้วอยู่ที่ชั้น `@` (**ตัวอักษรสีส้ม**) ยังไม่ใช่บล็อก
- `fill` กับ `solid` เท่านั้นที่ดันข้ามไปเป็นบล็อกทึบ

**คอนทัวร์รอบรูปคือสำเนาที่เบลอของตัวทึบ** ค่าที่ฟุ้งออกไปตกกลางบันได จึงถูก
เรนเดอร์เป็น `# @ $ ! ; : < + =` ไล่ออกไปเป็นวง ๆ เหมือนคอนทัวร์ของเกาะ
รัศมีเบลอผูกกับ `solid` — หนา 4-6 ช่องตอนยังเป็นตัวอักษร แล้วหดเหลือ 1 ช่องตอนทึบ

### คลื่น = แนวความร้อนที่กวาดผ่านผืนที่อยู่นิ่ง

ข้อสรุปนี้กลับหัวจากที่เคยเข้าใจ และเป็นตัวที่ทำให้ทุกอย่างเข้าที่

ไล่คลิปทีละเฟรม f036-f112 แล้วพบว่า **เกาะไม่เคลื่อนที่เลย** เกาะขอบซ้ายอยู่ที่
x 0-210 เท่าเดิมทุกเฟรมตั้งแต่ f052 ถึง f078 เปลี่ยนแค่ความลึกของแกน:

| เฟรม | แกนของเกาะขอบซ้าย |
| --- | --- |
| f052 | `==+++==` |
| f056 | `++<<<<++` |
| f064 | `<<::::<+` |
| f068 | `<:;;;:<+` |
| f078 | `!$$$!` `$@@$` |

และเกาะบนซ้ายที่เป็นแกนส้มตอน f072 **กลับเย็นเป็นฟ้าอีกครั้งที่ f084** — ก้อนไม่ได้
ย้ายไปไหน สิ่งที่ผ่านไปคือความร้อน

เพราะฉะนั้นโมเดลคือ: ผืนภูมิประเทศนิ่งสนิท มี "รอยความร้อน" กวาดผ่าน เกาะไหนโดน
ก็ไต่จากชั้นฟ้าขึ้นถึงชั้นส้ม แล้วเย็นลงเมื่อรอยผ่านไป

**ตัวคูณ ไม่ใช่ตัวบวก** — ย่านที่ไม่มีเกาะต้องดำอยู่เหมือนเดิม บวกเมื่อไหร่ได้แถบสว่าง
พาดกลางพื้นดำซึ่งไม่มีในคลิป มีการบวกเล็กน้อย (`0.06 × band`) ก่อนตัดเส้นระดับ
ไว้ให้รอยสร้างเกาะของตัวเองได้ตอนลอยผ่านที่ว่าง แต่ตัวหลักคือตัวคูณ

**เพดานสองระดับ** — พื้นหลังในคลิปไม่เคยติดสีส้ม แกนที่สว่างที่สุดของเกาะหยุดอยู่ที่
ชั้นคราม สีส้มเป็นของแกนรอยเท่านั้น:

```
bg = min( 0.70 + 0.27 × band ,  bg × (terrTop + 0.85 × band) )
```

`band = 0` → เพดาน 0.70 = `!` คราม / `band = 1` → 0.97 ขึ้นไป

### รอยเป็นเส้นที่ถูกลาก ไม่ใช่จุดที่ขยับ

วัดความยาวของช่วงที่ร้อนในแต่ละเฟรม:

| เฟรม | ช่วงที่ร้อน | ยาว |
| --- | --- | --- |
| f086 | x 740-940 | ~200px |
| f094 | x 940-1310 + หาง | ~370px |
| f098 | x 1000-1550 + หาง | ~550px |
| f102 | x 1080-1750 ปลายโค้งลง | ~670px |

**หัวเดินไปแล้วหางค้าง เส้นยาวขึ้นทุกเฟรม** = การลากเส้น จึงต้องวัดระยะจาก
"รอยที่ลากไปแล้ว" ไม่ใช่จากจุดเดียว: เก็บ 56 จุดบนเส้นทางตั้งแต่หางถึงหัว แล้ว
หาระยะที่ใกล้ที่สุดถึง**ส่วนของเส้น** (ฉายลงบนเซกเมนต์แล้วหนีบ 0-1)
วัดถึงจุดอย่างเดียวได้เส้นเป็นลูกปัดเรียงกัน

**รูปทรงหยดน้ำ** ความหนาแปรตามตำแหน่งบนรอย `drop = 0.13 + 0.87 × a^0.55`
หางเหลือ 13% แล้วอ้วนขึ้นจนเต็มที่ช่วงหัว ปลายหัวกลมได้มาฟรีจากการวัดระยะถึงเซกเมนต์

**แกนตัน + ชายขอบ ไม่ใช่ gaussian ล้วน** — gaussian มียอดจุดเดียวแล้วตกทันที
เส้นที่ได้บางและแบน ต้องมีแกนที่ค่าคงที่เต็ม (`FRONT_R`) แล้วค่อยไล่ระดับออกไป
(`FRONT_SKIRT`) ชายขอบนี่แหละที่ทำให้เห็น `# @ $ ! ; : < + =` ครบชั้นรอบตัว = ปริมาตร

## ห้า: โลโก้ J O E

ยกพาธมาจาก `JoeLettersSplash.tsx` ตรง ๆ ใช้พิกัด viewBox เดียวกัน
(`-10 -10 259 104`, หมึกกินช่วง x 0..239, y 0..84)

- **J** ตัวถังก้นมน + ลิ้นตรงกลาง + บากมุมซ้ายบน
- **O** กลีบวงรีสี่กลีบ
- **E** ตัวถัง + เดือยหน้า + ช่องกลางมุมมน + ช่องเปิดล่าง

### รอยเป็นตัวลากโลโก้เอง

**จุดสำคัญที่สุดของฉากนี้** ตัวอักษรไม่ได้ "โผล่ขึ้นมาเฉย ๆ" และไม่มีการส่งไม้ต่อ
ระหว่างคลื่นกับโลโก้ — รอยเดียวกันที่ลากข้ามจอมานั่นแหละที่ลากต่อเป็นตัว J O E
แล้วเนื้อของตัวอักษรถมตามหลังรอย

โครงของโลโก้ถูกแปลงเป็นพิกัดจอด้วยกรอบเดียวกับที่ `stampLogo` ใช้วางโลโก้:

```
จอ.x = 0.21 + viewBox.x / 239 × 0.58
จอ.y = 0.32 + viewBox.y / 84  × 0.36
```

รอยจึงทับตัวอักษรพอดี ครึ่งหลังของ `FRONT_PATH` (18 จุด) ลากตามลำดับ **E → O → J**:

| `lead` | ลากอะไร |
| --- | --- |
| .625 – .76 | **E** ขวาบน → ซ้ายบน → คานกลาง → ย้อนซ้าย → ซ้ายล่าง → ขวาล่าง |
| .79 – .878 | **O** ยอด → ซ้าย → ล่าง → ขวา ครบวง |
| .905 – 1.0 | **J** มุมขวาบน → ขอบขวา → ก้นมน → ขอบซ้าย → มุมซ้ายบน |

สองอย่างที่ทำให้เห็นว่ามัน "กำลังลาก":

- **รอยต้องนำหน้าเนื้อ** `build` เริ่ม f112 ตามหลังรอยราวแปดเฟรม ถ้าเริ่มพร้อมกัน
  ตัวอักษรจะโผล่พร้อมรอยจนดูไม่ออกว่ามีการลาก
- **แกนรอยต้องเป็นบล็อกทึบ** (`floor = band² × 1.06 × gain`) ถ้าอยู่แค่ชั้น `@`
  มันจะกลืนไปกับขอบฟุ้งของตัวอักษร

`ringFade` หรี่รอยที่ `build 0.86-1.0` เท่านั้น — รอยคือคนลากตัวอักษร ไม่ใช่ของที่
ต้องรีบเก็บ

### เนื้อในถมทีละชิ้น

```
fill_i = max( ease( clamp01( (p_i − 0.45) / 0.55 ) ), solid )
```

ชิ้นเริ่มติดสีตอนเดินทางไปได้ราวครึ่งทางของท่าเข้าตัวเอง แล้วเต็มพอดีตอนเข้าที่
ชิ้นที่ออกตัวก่อนจึงติดสีก่อน — ประกอบไปติดสีไปแบบเหลื่อมกัน ไม่ใช่พร้อมกันเป๊ะ

## หก: กับดักที่เคยเดินชนมาแล้ว

อ่านทุกข้อก่อนแก้ ทุกข้อคือบั๊กที่เกิดขึ้นจริงและเสียเวลาไปกับมันแล้ว

1. **ห้ามเจาะช่องว่างก่อนลากเส้นขอบ** เส้นขอบจะไปถมช่องว่างคืน
   ช่องกลาง E กับบากมุม J หายไป โลโก้อ่านเป็น `O W B`

2. **ต้องคืน `globalAlpha = 1` ก่อนเจาะ** ค่าที่ค้างจากเส้นขอบเป็น 0 ตอน `solid = 1`
   ช่องว่างทั้งหมดไม่ถูกเจาะ โลโก้กลายเป็นก้อนตัน

3. **มาสก์ "ร้อน" ต้องผูกกับ `fill` ไม่ใช่ "ชิ้นที่กำลังเคลื่อน"**
   ถ้าผูกกับการเคลื่อน พอทุกชิ้นเข้าที่แล้วมาสก์ว่าง ทั้งโลโก้ค้างเป็นตัวอักษร

4. **รัศมีคอนทัวร์ต้องใหญ่ตอนต้น** เคยตั้งกลับด้าน (`0.5 + 0.5 × build`)
   ก้อนที่กำลังก่อตัวเลยเป็นเส้นบางแทบมองไม่เห็น

5. **เส้นขอบ 4 หน่วยบางเกินไป** พอย่อมาที่สเกลของตารางเหลือไม่ถึงหนึ่งช่อง
   จมหายไปกับการเบลอ ใช้ 10 (ราวสามช่อง)

6. **`guide` ต้องคูณเฉพาะค่าที่รอดจากการตัดแล้ว** ถ้าคูณทั้งผืน ทุกช่องถูกยกขึ้น
   ชั้นคราม ได้สนามจุดครามเต็มจอ — เป็นสิ่งที่ทำให้ภาพรวมดูไม่เหมือนคลิปมากที่สุด

7. **`spin` ห้ามหมุนเต็มรอบ** โลโก้จะแบนเป็นเส้นตรงกลางทางจนอ่านไม่ออก

8. **ห้ามใช้ state ใน render loop** `drive` เป็น ref เท่านั้น

9. **ปื้นขาวต้องล็อกไว้จนถึง f150** ไม่งั้นมันไปเกาะหัวที่กำลังก่อตัว
   ทำให้หัวเป็นสีขาวแทนที่จะเป็นส้ม

10. **จุดนำสายตาต้องเบาและเล็ก** ลองแรกตั้ง `a = 0.95`, `r = 12-17` ช่อง
    ได้จานส้มทึบยักษ์กลบตัวอักษรที่กำลังก่อตัวอยู่ข้างใต้ทั้งตัว
    ค่าที่ใช้อยู่คือ `a = 0.42`, `r = 3.2-5.5` — แกนถึงชั้น `$ @ #` พอดี

11. **เส้นทางของจุดต้องอยู่ในกรอบที่ฉายลงจอแล้วยังเห็น** พิกัดเป็นระบบ viewBox
    ซึ่งกินแค่ 58% ของความกว้างจอ ตั้ง x เป็น `-320` แล้วมันอยู่นอกจอตลอด
    ช่วงที่ควรจะเห็นมันเดิน

---

12. **รอยกับ `hal` ทำให้ตัวอักษรติดกันเป็นก้อนเดียว** เส้นขอบ `lineWidth = 10`
    หน่วยโลโก้คือราวสามช่อง ยื่นออกนอกรูปข้างละช่องครึ่ง แต่ช่องว่างระหว่าง J กับ O
    ในโลโก้จริงกว้างแค่ 4 หน่วย (~หนึ่งช่อง) มันเลยถมช่องว่างจนอ่านเป็น `we`
    ต้องหดเป็น `10 × (1 − solid × 0.92)` และลด `hal` เป็น `0.8 − 0.55 × solid`

13. **ตัวคูณระดับของโลโก้ต้องไม่เกิน 1** ของเดิมสูงสุด 1.22 ช่องที่โดนตัวอักษรแค่ 82%
    ก็ถูกดันข้ามไปเป็นบล็อกทึบ ขอบตัวอักษรเลยบวมออกจนชนกัน

14. **การหรี่รอยต้องคูณ "หลัง" ยกกำลังสอง** `floor = band²` ถ้าเอาตัวหรี่ไปคูณที่ `band`
    ค่าจะตกกำลังสอง (0.79 → 0.62) รอยหลุดจากขั้นบล็อกทึบทันทีที่ `build` เริ่ม
    เกิดช่วงที่ไม่มีอะไรบนจอเลยราวยี่สิบเฟรม

15. **ริบบิ้นห้ามจางตาม `gain`** ตอนท้ายพื้นหลังเฟดหายจนดำสนิทแต่ตัวริบบิ้นยังอยู่ครบ
    ถ้าคูณ `gain` ตรง ๆ มันหายไปพร้อมพื้นหลัง

16. **วัดระยะถึงจุดที่สุ่มไว้ไม่พอ** พอรอยยาวขึ้น ช่องว่างระหว่างจุดกว้างกว่าความหนา
    ได้เส้นเป็นลูกปัดเรียงกัน ต้องฉายลงบนเซกเมนต์แล้วหนีบ 0-1

17. **เส้นทางต่อด้วย lerp เชิงเส้นจะหักมุมทุกจุดที่วัดมา** ใช้ Catmull-Rom
    (ผ่านทุกจุดควบคุมพอดี ต่างจาก Bezier) ตำแหน่งที่วัดจากเฟรมจริงจึงยังตรงเป๊ะ

18. **หางของรอยต้องคลายออก** ถ้าเก็บทั้งประวัติไว้เต็มแรง รอยจะสะสมจนท่วมจอ
    แทนที่จะเป็นเส้นเดียว — `release = min(1, a / 0.12)`

- ค่าปัจจุบันของ `drive` ทุกฟิลด์

ได้ภาพเดิมเสมอ

### เทียบกับคลิปอ้างอิง

**ห้ามจับภาพด้วยการรอเวลาจริง** เวลาที่หน้าโหลดเสร็จไม่แน่นอน เฟรมที่ได้เลยเพี้ยน
ให้ seek ไทม์ไลน์ผ่านแถบ scrub ของแผงดีบักโดยตรง (`.intro-debug-scrub`,
ตั้ง `value` แล้ว dispatch `input`) จะได้เฟรมตรงเป๊ะทุกครั้ง — `seek(t)` เรียก
`pause()` ให้ด้วย



อย่าตัดสินด้วยการมองภาพของตัวเองอย่างเดียว วิธีที่ได้ผลคือจับภาพที่เวลาตรงกับ
เฟรมอ้างอิง (`t = f / 30 × SLOW`) แล้ววางเทียบข้างกัน ปัญหาที่หาไม่เจอมาหลายรอบ
โผล่ออกมาทันทีที่เห็นสองภาพติดกัน
